# capsule queue items (as run)

the exact scripts that ran the Microduck training, probes, proof takes and clip cuts on the RTX 5090 tower ("capsule"), one file per queue item, copied from the private ops log on 2026-10-23. they are records of what ran, not a polished CLI: paths point at the tower's home directory and the mjlab / Microduck checkouts there. the reusable pieces live in `../`, `../../tools/` and `../../conditions/`.

simulation only. nothing here has run on the real robot yet.
